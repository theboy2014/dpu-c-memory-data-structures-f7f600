# Heap Memory and Data Structures in C

A beginner-to-intermediate project that teaches manual memory management in C — the heap, malloc and free, ownership and lifetime, and the bugs that follow (leaks, double-free, use-after-free). You build a small linked list of device descriptors and learn to find leaks with Valgrind. This is the discipline every driver and firmware module depends on.

Built step-by-step with [KhwajaLabs Build](https://khwajalabs.com).

## Stack
- C
- malloc
- Heap
- Structs
- Linked Lists
- Valgrind
